# Zombie Escape

Roguelike de zombis en pixel art: Johnny, un conserje, limpia un edificio infestado apartamento a apartamento.
Hecho con **Godot 4.7** (se está pasando aquí desde la versión de navegador).

Para jugar: abrir Godot 4.7, **Importar** → `project.godot` y pulsar **F5**. Se anda con WASD, las flechas o el mando.

Notas de trabajo y estado de cada fase: [`CLAUDE.md`](CLAUDE.md).
